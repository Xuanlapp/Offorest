# Offorest Desktop Release 0.1.12

## Thay doi

- Tang version ung dung tu `0.1.11` len `0.1.12` bang script release patch.
- Build lai frontend vao thu muc `app-dist` truoc khi dong goi Electron.
- Dong goi lai bo cai Windows moi vao thu muc `release`.

## Lenh da dung

```bash
npm run release:patch
```

## Ket qua

- Version trong `package.json` da la `0.1.12`.
- Tao thanh cong file `release/Offorest Setup 0.1.12.exe`.
- Tao thanh cong file `release/Offorest Setup 0.1.12.exe.blockmap`.

## Ghi chu

- Electron Builder co canh bao dang dung default Electron icon vi app chua cau hinh icon rieng.
- Qua trinh build thanh cong, khong gap loi chan release.
